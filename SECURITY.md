# Security Policy

Project Walrus is an autonomous AI agent security and control platform maintained by [BlueIce](https://blueice.one). Security is our foundational priority.

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, detection bypass, or sandboxing issue in Project Walrus, please report it via email:

* **Email:** [security@blueice.one](mailto:security@blueice.one)

### Please Include:
- A description of the vulnerability or bypass technique.
- Steps to reproduce or a proof of concept (PoC).
- Affected components (e.g. Tool Broker, Injection Detector, Dependency Scanner, IPC Preload Bridge).
- Potential impact assessment.
- Your name, handle, or organization for attribution (if desired).

## Responsible Disclosure

We follow responsible disclosure principles:
1. **Initial Response:** We will acknowledge receipt of your vulnerability report within 48 hours.
2. **Assessment:** Our engineering and security research team will investigate and determine severity within 5 business days.
3. **Remediation:** We aim to release a patch within 30 to 90 days depending on severity.
4. **Public Advisory:** We will credit your contribution in the release notes upon patch deployment.

Thank you for helping keep the open-source AI ecosystem safe.
